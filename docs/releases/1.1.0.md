# Internet Speed Reader 1.1.0

Live traffic monitoring now starts automatically and recovers from delayed readings,
missing counters and network changes. The menu bar defaults to download and selects
sustained upload activity. Opening the panel still provides both live directions and
manual Go/Stop capacity tests.

## Changes

- Fixed Low Power Mode readings freezing when a five-second timer fires late.
- Added elapsed-time smoothing, freshness tracking and a distinct unavailable state.
- Filtered small outgoing control traffic before selecting the upload direction.
- Validated completed download and server-confirmed upload transfers; kept failed,
  interrupted and unverified data out of final results.
- Added per-direction quality, bounded transfer budgets, cancellation ownership,
  automatic cooldown updates and compatibility with older local history.
- Improved Apple Deep Test process cleanup and made Settings reliably accessible.
- Added repository artwork, privacy documentation and automated publication checks.

## Download and trust

`InternetSpeedReader-1.1.0.dmg` supports Apple silicon and Intel Macs running macOS 14
or later. Drag the app to Applications. Existing preferences and history remain local.

This public package is **ad-hoc signed, not Developer ID signed or Apple notarized**.
It does not contain the maintainer's personal certificate, API credentials, preferences
or test history. Gatekeeper may block it. Keep macOS security protections enabled;
reviewing and building the source is an alternative.

SHA-256:

```text
ab246a1cbbe256000bc363ba4ad48ebdcedff9ae25674082544c71c42b98e72d  InternetSpeedReader-1.1.0.dmg
```

`SHA256SUMS` is supplied with the package. A checksum detects changed bytes; an ad-hoc
signature does not establish a developer's identity.

## Validation and limits

All 125 core tests and eight publication-scanner regression tests passed. The Release
build is universal; disk-image integrity and signatures were checked. See the
[verification summary](../VERIFICATION-1.1.md) for the scope of live checks.

Cloudflare refused manual download tests with HTTP 403 during verification. The app
reports this as a failure and saves no invalid result; Apple Deep Test completed as
an alternative. Three successful Cloudflare comparisons, confirmed physical system
sleep/wake and next-login verification remain incomplete. Results are not guaranteed
to match Ookla or another provider. Capacity tests remain manual and consume bandwidth.

See [Security](../../SECURITY.md) before sharing logs or reporting a vulnerability.
