# Internet Speed Reader 2.0.0

Both directions, always visible, with numbers that no longer round real traffic away to
zero. A capacity test that survives one provider refusing.

## Why this release exists

The app was running and measuring correctly, and the menu bar still showed `0.0`. Two
display rules caused it: the default layout showed one direction at a time, and the
formatter printed a single decimal after converting into the chosen unit, so with
megabytes per second selected everything below 0.4 Mbps rendered as zero. Separately, the
capacity test had a single provider, and that provider had started refusing one of the
request sizes the app asks for.

## What changed

- The menu bar shows download and upload together by default, and the direction currently
  transferring is drawn in bold.
- Small but real traffic reads as a small number (`0.02`, `<0.01`) instead of `0.0`. Only a
  genuine zero shows `0.00`; an unavailable reading still shows a dash.
- The panel uses the same unit as the menu bar. Latency and responsiveness are never
  converted.
- A brief gap in readings dims the last numbers for a moment instead of blanking them, and
  ordinary network events such as AirDrop or a DHCP renewal no longer disturb the meter.
- GO tries Cloudflare's measurement host, then the classic host, then Apple's built-in
  tool, and reports which one produced the number. A provider that refuses is skipped for
  a few minutes rather than retried immediately.
- Every request now carries the headers the classic host requires, and request sizes avoid
  the range it refuses.

## Upgrading

Preferences, history, the outage log and launch at login are preserved. A stored
preference for the old single-number layout is moved to the two-row layout once; the old
layout stays selectable in Settings.

Public builds are signed ad hoc and are not notarised by Apple.
