# Project artwork

`logo.png` is the project's cyan and blue gauge mark. `hero.png` is the README
banner. Both were created with the built-in image-generation tool for this project.
The banner is an illustration, not an application screenshot or a measured result.
No personal desktop, network information or third-party company logo was used.
The files are distributed under this repository's Apache-2.0 license; their
generation provenance is retained.

## Logo prompt

Use case: logo-brand. Create a polished original logo image for the open-source
macOS utility 'Internet Speed Reader'. Asset: square 1024x1024 app/project mark.
A minimal, highly legible cyan and blue speed gauge ring that subtly forms a
downward arrow and an upward pulse, on a deep midnight navy rounded-square field
with generous outside transparent margins. Restrained professional macOS utility
aesthetic, crisp geometric silhouette, smooth edges, subtle depth, striking at
small size. No text, letters, numbers, slogans, watermarks, existing company marks,
devices, screenshots, personal data, or extra objects. Keep the mark simple and
original; genuine alpha transparency outside the rounded square.

## Banner prompt

Use case: ads-marketing. Asset type: wide GitHub README hero banner, 1536x640
composition. Use the attached Internet Speed Reader logo as the brand reference;
preserve its cyan-blue speed-gauge and download/upload motif. Compose a refined
dark navy editorial banner with the icon on the left at moderate scale and
carefully typeset title on the right. Exact title on two lines: "Internet Speed
Reader". Exact smaller subtitle: "Live traffic. At a glance." Thin, restrained cyan
and blue flowing graph lines in the background suggest network throughput, with
generous negative space and high contrast. Modern native macOS utility feeling,
clean typography, subtle illumination, crisp edges. This is brand artwork, not a
screenshot; do not draw a desktop, a real app panel, mock speed numbers, devices,
logos of other companies, personal information, extra claims, watermarks, tiny
unreadable writing, or other text.
